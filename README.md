Sales Data Analysis
Project Overview
This is my first data analytics portfolio project. I analyzed sales data to understand business performance, product profitability, and sales trends.

TOOLS USED
- python
- pandas
- Mtplotlib
- Jupyter Notebook

  Key Findings
  - Total Sales: $2,297,200.86
  - Total Profit: $286,397,02
  - Total Orders: $5,009
  - Most Profitable Category: Technology
  - Area for Improvement: Furniture generated relatively low profit compared with its sales

  Business Recommendation
  Review furniture pricing, discounts, and costs. Investigate products that generate high sales but make losses.
